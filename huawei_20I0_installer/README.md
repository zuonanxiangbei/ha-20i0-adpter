# 华为智选 欧普智能台灯 Pro（20I0）适配器安装器

给 [xiasi0/ha-huawei-smarthome](https://github.com/xiasi0/ha-huawei-smarthome) 集成用的
单品适配器安装器。适配：华为智选 欧普智能台灯 Pro，型号 MT615-D20WTT，prodId `20I0`。

## 为什么需要它

安卓（无 root）不允许文件管理器访问 HA 的数据目录，手动放文件进不去。
这个安装器由 HACS 下载，HA 启动时自动把适配器复制到正确位置，不需要动文件系统。

## 装完会得到什么

| HA 实体 | 功能 |
| --- | --- |
| `light.台灯` | 开关 / 亮度（3–255）/ 色温（3000–5000K） |
| `select.灯光模式` | 阅读 / 书写 / 最爱 / 智能 / 夜间唤醒 |
| `switch.夜灯` | 夜灯开关 |
| `switch.学习模式` | 番茄钟等学习模式启停 |
| `select.学习模式` | 番茄 / 课堂 / 考试 / 自定义 |

## 安装步骤

1. HACS → 右上角 `⋮` → 自定义仓库
2. 地址填本仓库地址，类别选 **Integration（集成）**
3. 搜索 `20I0` → 下载
4. **重启 Home Assistant**
5. 重启后：设置 → 设备与服务 → Huawei SmartHome → `⋮` → **重新加载**
6. 台灯设备页出现实体，完成

> 第 4 步重启时安装器复制文件，第 5 步让集成读到它，两步都不能少。

## 排错

日志（`设置 → 系统 → 日志`）里搜 `20I0`：

- 出现「台灯适配器已写入 …」→ 成功，去重载集成
- 出现「台灯适配器写入失败」→ 检查 huawei_smarthome 集成是否已安装
- 实体仍不出现 → 删除华为集成重新添加登录，或再重启一次
